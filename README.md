# CV

Personal CV as a living document.

## About

This repository is not a resume and not a cover letter. It is an **append-only
living document**: a set of facts that reflect personal growth in software,
without positioning, metrics, or marketing.

The document may have a narrative style. If something is missing, most likely
there was no such experience at all.

The purpose is twofold:

1. Keep an honest record of the journey — a chronological list of
   biographical facts about building software.
2. Provide a reliable source of truth to generate a consistent projection
   for a specific job opening — a tailored resume based on an honest history.

The distinction:

- **CV** — _"course of life"_ (Latin): a chronicle of biographical facts.
- **Resume** — _"summary"_ (French): a compressed projection of the biography
  adapted to the requirements of a particular vacancy.
